# Compact Windows controls and Mac-port transfer

## Feature specification

The Windows WPF viewer should expose more image area while keeping its controls readable and recognizable. This release adapts the public macOS transfer guide at commit ed55d65f85e623d531367a7704d44cf7c0668b42. It preserves Windows input conventions, exact opened RT objects and clinical source bytes. It does not replace WPF or import the Mac worker.

1. Buttons and closed dropdowns use a shared 28-DIP minimum height, 12-DIP text and smaller padding. Dropdown items keep at least 26 DIP height. Text remains visible at Windows scaling; keyboard focus is blue. Selected controls and checked controls retain their existing state bindings. There is no fixed maximum height that clips large text.
2. View buttons display Native, Axial, Coronal, Sagittal, 2 x 2 and 3D beside 20-DIP vectors. The section views share a cube outline with different filled section planes. Ctrl+1 through Ctrl+6 keep the existing order. The existing horizontal overflow path keeps controls reachable on narrow windows. Settings uses a vector gear inside the same button dimensions.
3. Empty or placeholder plan labels use a UI-only fallback, RT-Plan N with beam count. Dose choices use stable session ordinals, summation type and maximum/unit so two grids with identical names are distinguishable. Original labels remain in selection tooltips and export identities. All choices still bind the original PlanData or DoseGrid instance; ordinal is never an association key.
4. MLC leaf tips get a dark backing and a bright screen-space edge, independently of whether the aperture is closed. X and Y jaw guides use separate yellow and lavender colors with X1/X2/Y1/Y2 labels. A Jaw guides checkbox hides only guides, never the jaw occlusion. Missing jaw positions do not create guides. Both leaf layers and dynamic collimator rotation stay supported.
5. The MLC toolbar shows a short machine label with detailed identity tooltip. Unknown machines remain unknown. The movable LINAC/CT context retains its existing behavior.
6. Repeated field-extent queries share one immutable-per-loaded-beam cache. This removes repeated scans of all control points in overlay/cache playback paths. Cache ownership is weak by beam object identity, so closing datasets does not create an unbounded strong-reference patient cache. Loaded PlanBeam objects are not edited after parsing; no geometry mutation UI exists. A different beam instance recomputes its extent.

## Detailed implementation plan

- Theme.cs and Theme.xaml: reduce button/dropdown padding and spacing. Bind dropdown padding in its selection presenter rather than hard-coding the old margin; constrain popup height as before, keep item scrolling, and add focus indication on the parent ComboBox. Keep native Windows scaling and text sizes. Do not globally shrink content lists or volume columns.
- ViewerNavigation.cs: replace section drawings with the transfer-guide cube paths, draw inside a fixed 24-unit canvas, freeze drawings, show labels for every mode, and avoid duplicate shortcut tooltips. Keep existing Tag values and click handlers.
- ViewerSettings.cs / Theme.cs: use a native frozen vector gear. Keep tooltip and automation name readable.
- ViewerObjectLabels.cs (new), ViewerLoading.cs, ViewerWorkspace.cs and ViewerRt.cs: centralize display-only plan/dose labels. Use loaded collection index + 1 as the stable session ordinal; refresh loading rows without changing reference identity. Plan tooltip includes original Label; dose tooltip includes original Label and known numeric metadata, without filenames. Apply labels to hierarchical plan picker, dose checklist, DVH dose picker and sum-source captions. Do not modify Rt/PlanData.cs, DoseGrid data, CSV naming or file associations.
- MlcPlaybackControl.cs and MlcAnatomy.cs: add Jaw guides control in the existing horizontal toolbar; draw guides after jaw occlusion and anatomical outlines, under the existing collimator transform. Create screen-space pens once, not once per leaf. Draw actual leaf tips above leaf fills from both layers; clip tips to real jaw bounds where present. Guide labels use constant font size and remain tied to actual coordinates. Compact 3D aperture display preserves its current behavior.
- BeamExtentCache.cs (new) and MlcAnatomy.cs: wrap the existing numeric extent formula in ConditionalWeakTable<PlanBeam, Entry>; preserve the existing public BeamExtent method. Do not change geometry, clipping, projection cache identity or dose computations. A targeted test verifies equal values and distinct beam entries; a repeat-query timing compares cached lookup with the same uncached formula.

## Deliberately separate work

Standard/STX dose presets based on prescription or body D0.035 cm3 require a separate numerical normalization change. This UI/performance release retains the current explicit Gy/percentage semantics. Existing CT-volume reuse, exact projection caching, field-only updates and transform-based LINAC animation should be inspected and preserved, not rewritten merely because the Mac guide mentions them. This work does not claim macOS runtime validation.

## Review decisions and implementation detail

- Shared compact styling was chosen over a toolbar-only style so settings dialogs and dropdown items have consistent spacing. Content-list text/volume columns are not reduced. Horizontal overflow was retained instead of wrapping (which steals image height) or a new overflow menu (which conceals existing controls).
- Supported full-layout checks use 1024 and 1600 **DIP**, not physical pixels, with both sidebars. Bitmap DPI is 96, 144 and 192; for example 1024 DIP produces 2048 physical pixels at 200%. The existing two-panel minimum is 923 DIP. Below this width users must close a sidebar; this update does not claim a new responsive panel layout. Whole-layout screenshots, not only isolated controls, are inspected. Default button chrome drops from approximately 28 to 24 DIP for plain text but retains a 28-DIP minimum; labeled icon buttons fit a 32-DIP row including margins. Closed dropdown padding falls from 6 vertical DIP to 3 per side.
- Original `DosePlanLabel` remains the identity formatter used to create a generated dose label. New `DosePlanDisplay` is only for visible sum choices and contributor captions. A generated sum is labeled `Generated sum` plus its existing label, without a source ordinal. Source PlanData.Label and DoseGrid.Label remain unchanged.
- Fills for all selected MLC layers precede the final backed tip pass. The pass respects LayerIndex and clips tips to each known jaw axis. Equal/crossed jaw intervals are closed, never sorted into an opening. Unknown axes do not imply jaws. Guide visibility affects only the final colored lines/text. Compact 3D apertures retain their original thin edges and rendering order. Collimator transform applies to every layer, guide and anatomical overlay.
- The extent cache also retains the existing jaw-based miniature extent used in BeamFieldOverlay. Each installed weak-table entry has Lazy values for thread-safe cold access. No persistent cache is introduced. Tests cover equality, distinct source identity, parallel first access and weak lifetime; timings are informational.
