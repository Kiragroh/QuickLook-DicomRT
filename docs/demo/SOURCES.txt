DICOM RT — Media provenance — 0.2.2

The main source is the user-authorized public nonpatient benchmark: 191 CT images, one RTSTRUCT with 55 structures, one RTPLAN and one RTDOSE. DICOM files are read-only and are not distributed. It contains no MR, REG or second plan; fusion and summation are described without synthetic examples.

Screenshots and frames are actual WPF viewer/control renders at 1600 × 900. Identifying tag values were redacted in memory. The separately approved dual-layer MLC demonstration uses a whitelist display model with generic labels, actual technical angles and leaf geometry; no patient image, identifiers, original isocenter coordinates or source paths are included. Its standalone plan control also illustrates RTPLAN without CT.

Seven six-second MP4 videos were composed locally with HyperFrames 0.8.78 using actual settled viewer states. They are feature demonstrations, not measurements of live frame rate or actual treatment delivery time. No DICOM data was sent to a media service. No synthetic DICOM image data or generated application screenshots are included. The shared human is an explicitly schematic orientation model within the actual viewer.

DVH, reformatted outlines, skin/bone thresholds and bounded/smoothed 3D surfaces are inspection approximations. The mini linac is a schematic orientation aid, not a collision model or patient registration.
