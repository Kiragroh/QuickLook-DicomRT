# Viewer terms

| Term | Meaning |
| --- | --- |
| Plan context / Plan-Kontext | Explicitly associated plan, structures, doses and image series |
| Structure / Struktur | One source ROI, with name and optional contour description |
| Dose overlay / Dosisgitter | One independently visible registered source dose, or the derived sum |
| DVH dose / DVH-Dosis | Dose used for the current cumulative DVH; independent of overlay visibility |
| Dose reference / Dosisreferenz | Physical Gy value assigned to 100% by the selected preset or explicit manual choice |
| Standard | User-confirmed prescription/D0.035 normalization and 95/100/105/107/110/120% upper stops |
| STX | User-confirmed ten-percent palette with D0.035 as 100% |
| Isocenter / Isozentrum | Actual mapped control-point isocenter; multiple source points remain separate |
| Control point / Kontrollpunkt (CP) | Recorded or interpolated source beam state; CP/s describes preview speed |
| Jaws / Blenden | Actual X1/X2 or Y1/Y2 beam-limiting device positions |
| Orientation context / Orientierung | Movable axial field arrangement and LINAC schematic in MLC workspace |
| Neutral fields | Treatment fields without one active highlight |
| Partial coverage | Unknown dose outside the covered part of a structure remains unknown |
| Folder selection / Ordner auswählen | Local read-access choice; no transfer or sharing with another person |
| Search scope / Suchbereich | Bounded nearby folder tree to inspect for referenced DICOM objects |
| Plan choice / Plan auswählen | Explicit choice among plans referring to the selected image or structure |
